# Brightly releases

WAV files (stereo, 44.1kHz, 16-bit) of every release by my band, [Brightly](https://wewerebrightly.com), with cover art.

Status: archived. Put together in 2023 as a complete copy of the releases. Nothing new is coming.

Live: https://wewerebrightly.com

## What's in it

Each release has its own folder, with the tracks numbered in order and a `cover.jpg`.
